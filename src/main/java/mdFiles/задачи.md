
## Задание 1. Что делает метод? — 8 минут

Это метод `splitString` из настоящего проекта WebAppraiserBackend. Для него нужны `java.util.List` и `java.util.ArrayList`.

```java
public static List<String> splitString(String input, int chunkSize) {
    List<String> result = new ArrayList<>();
    if (input == null || chunkSize <= 0) {
        return result;
    }

    for (int i = 0; i < input.length(); i += chunkSize) {
        int end = Math.min(i + chunkSize, input.length());
        result.add(input.substring(i, end));
    }

    return result;
}
```

Сначала запиши результат каждого вызова, затем проверь запуском. Для запуска помести `splitString` и `public static void main(String[] args)` в один класс. В `main` вставь следующие строки:

```java

System.out.println(splitString("ABCD", 2));
System.out.println(splitString("", 2));
System.out.println(splitString(null, 2));
System.out.println(splitString("ABC", 0));
```

Объясни две вещи: зачем здесь `Math.min` и изменится ли переданная строка.

## Задание 4. Один метод для разных типов — 10 минут

Прочитай обычный метод, работающий со строками:

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

public class ListTools {
    public static List<String> uniqueNames(List<String> source) {
        if (source == null) {
            throw new IllegalArgumentException("source must not be null");
        }
        List<String> result = new ArrayList<>();
        Set<String> seen = new HashSet<>();
        for (String name : source) {
            if (seen.add(name)) {
                result.add(name);
            }
        }
        return result;
    }
}
```

Предскажи результат `ListTools.uniqueNames(Arrays.asList("Ира", "Олег", "Ира"))` и скажи, изменится ли исходный список.
